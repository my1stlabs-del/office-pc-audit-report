# 회사/기관 보고서 제출용 PC 보안점검도구 v1.0.0

KISA 점검도구가 사라진 뒤, PC 보안점검을 뭘로 하고 보고서는 어떻게 만들어야 할지 막막했습니다. 그래서 AI의 도움을 받아 PC의 보안 상태를 확인하고, 결과를 보고서로 정리할 수 있는 프로그램을 만들었습니다.

E나라도움 등의 PC 보안점검 기준을 참고했고, **자동 점검 19개 항목과 직접 답하는 수동 질문 8개**를 담았습니다. 점검 결과는 HTML 보고서로 저장해 확인하거나 인쇄할 수 있습니다.

PC 설정을 자동으로 바꾸거나 기존 파일을 수정하지 않습니다. 프로그램이 직접 만드는 파일은 저장을 확인한 HTML 보고서뿐이며, 보고서를 담을 `결과출력` 폴더도 저장할 때만 만듭니다.

보안점검 보고서를 어떻게 작성해야 할지, 어떤 기준으로 확인해야 할지 고민이셨다면 편하게 활용해 주세요. 제출용으로 사용하실 때는 해당 기관의 양식과 기준도 함께 확인해 주세요.

## 자동 점검 19개

1. Windows 지원 상태
2. 최근 보안·누적 업데이트 설치 기록
3. 자동 업데이트 설정
4. Defender 실행·실시간 보호
5. Defender 보안 정의 업데이트
6. 타사 백신 등록 및 승인·라이선스 확인 안내
7. Windows 방화벽 상태
8. 원격 데스크톱 설정
9. SMBv1 사용 여부
10. 공유폴더 존재 여부
11. Guest 계정 활성 여부
12. 로그인 계정 유형·최소 암호 길이 정책
13. 로컬 계정 잠금 정책
14. 자동 로그인 설정
15. 시스템 드라이브 암호화 상태
16. 화면 자동 잠금 설정
17. 사용자 계정 컨트롤(UAC)
18. Secure Boot 활성 여부
19. TPM 버전·준비 상태

## 수동 확인 8개

1. 불필요한 개인정보 파일 정리
2. 개인정보 파일 암호화·접근 제한
3. 최근 6개월 내 중요 자료 백업·복구 확인
4. 퇴사자·미사용 계정 및 불필요한 관리자 권한 정리
5. 로그인 인증 및 길고 고유한 암호 사용
6. 공유폴더·원격접속의 필요성·접근 권한 확인
7. 타사 백신의 업무용 라이선스 확인
8. 보안 사고·악성코드 의심 증상 확인

## 실행과 보고서 저장

Windows 10/11 x64와 .NET Framework 4.8 환경에서 사용합니다. 배포 ZIP을 풀고 `OfficePcAudit.exe`를 실행하면 됩니다. 함께 제공되는 `OfficePcAudit.exe.config`는 같은 폴더에 두세요.

일반 권한으로 실행할 수 있지만 TPM·드라이브 암호화 등 일부 항목은 관리자 권한이 필요할 수 있습니다. 프로그램이 자동으로 권한 상승을 요청하지는 않으며, 조회하지 못한 항목은 ‘확인 불가’로 표시합니다.

자동 점검 → 수동 질문 → 정보 입력 → 보고서 저장 순서로 진행합니다. 보고서는 실행 폴더 아래 `결과출력`에 새 HTML 파일로 저장됩니다. 브라우저에서 열어 확인하거나 `Ctrl+P`로 인쇄·PDF 저장할 수 있습니다.

실행 파일은 코드서명되어 있지 않습니다.

## 결과 읽기

결과는 **통과 / 부분통과 / 조치 필요 / 수동 확인 필요 / 확인 불가**로 구분합니다. 조회 오류·권한 부족·시간 초과는 통과로 처리하지 않습니다.

Microsoft 계정은 로그인 계정 유형만 확인하므로 ‘부분통과’로 표시하며, 통과 건수에는 합산하지 않습니다. 인증 수단·복구 정보·최근 로그인 활동은 직접 확인하고 검토 의견에 기록해 주세요. 로컬 계정의 최소 암호 길이 정책도 실제 암호 길이나 강도를 검사하는 것은 아닙니다.

점검 기준과 Windows 지원기간 표는 프로그램에 내장되어 있으며 자동 갱신되지 않습니다. 결과는 보안 상태를 확인하기 위한 참고 자료로, PC 전체의 안전이나 기관별 제출 요건 충족을 보장하지는 않습니다. 악성코드 감염 여부나 업데이트가 실제 최신인지도 보증하지 않습니다.

## 정보 처리와 사용 시 참고사항

PC 이름·계정명·장비 기본 정보·보안 설정과 직접 입력한 이름·응답 등이 보고서에 포함됩니다. 암호·PIN·복구키, 제품키, 장비 일련번호, IP/MAC 주소, 개인 문서 내용·목록, 브라우저 기록은 수집하지 않습니다.

프로그램 자체의 외부 전송·원격 조회·자동 업데이트 기능은 없습니다. HTML 보고서도 외부 글꼴·이미지·스크립트를 불러오지 않습니다. 다만 실행 중 통신과 Windows 공급자의 부수 동작을 별도로 계측해 검증한 것은 아닙니다.

점검 권한이 있는 PC에서 사용하고, 보고서에는 내부 정보가 담기므로 공개 저장소에 올리지 마세요. 실행 위치는 네트워크 공유나 동기화 폴더를 피해 쓰기 가능한 로컬 폴더를 권장합니다. 암호·인증 코드·복구키는 의견란에도 입력하지 마세요.

보고서는 편집 가능한 HTML이며 전자서명·위변조 방지 기능은 없습니다. 설정 변경·백신 검사·자동 수정 기능도 제공하지 않습니다.

## 라이선스·출처

현재 별도의 오픈소스 라이선스는 지정하지 않았습니다. 코드의 이용·수정·재배포 허용 범위는 별도로 정할 예정입니다. 소스 공개만으로 자유로운 재사용·재배포를 허용하는 것은 아닙니다.

Windows와 .NET Framework 기본 구성요소를 사용하며, 별도 타사 라이브러리는 포함하지 않습니다. Windows/.NET DLL과 글꼴 파일도 배포본에 포함하지 않으며, 해당 구성요소의 이용 조건은 각 Microsoft 제품 약관을 따릅니다.

세부 조회 방식과 판정 근거는 아래 점검 기준·조치 안내 문서에 정리했습니다.

## 소스 빌드와 패키징

Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
.\build.ps1 -Test
.\tests\review-source.ps1
.\tests\review-repository.ps1
```

빌드 결과는 `dist/OfficePcAudit.exe`입니다. 인터넷·NuGet·추가 PowerShell 모듈 없이 Windows 기본 C# 컴파일러를 사용합니다.

`package.ps1`은 테스트와 검사 후 `배포버전/1.0.0` 폴더와 ZIP을 생성합니다. 배포 ZIP에는 소스에서 새로 빌드한 허용 파일만 넣습니다.

Git에는 소스·테스트·빌드 및 패키징 스크립트·문서·가상 예시만 포함합니다. 과거 작업물 보관용 `old/`, 빌드 결과인 `dist/`, `배포버전/`, 실제 보고서와 ZIP은 Git에서 제외합니다. 실제 보고서가 들어갈 수 있으므로 강제 추가(`git add -f`)하지 마세요.
