# 회사/기관 보고서 제출용 PC 보안점검도구 v1.0.0

회사/기관에 제출할 보안점검 보고서 작성을 돕기 위해 Windows PC의 설정을 조회하고 한국어 HTML 보고서를 만드는 도구입니다. 자동 19개 항목과 수동 8개 질문을 제공합니다. 설정 자동 변경·원격 접속·백신 검사 실행 기능은 없습니다.

저장소 이름: `office-pc-audit-report` / 버전: `1.0.0`.

제출 전 해당 회사/기관의 지정 양식과 점검 기준에 맞는지 확인해야 합니다. 이 도구의 보고서가 모든 기관의 제출 요건을 충족하는 것은 아닙니다.

## 실행 및 빌드

Windows x64와 .NET Framework 4.8이 필요합니다. Windows PowerShell에서 ./build.ps1 -Test, ./tests/review-source.ps1, ./tests/review-repository.ps1을 실행합니다.

빌드 결과는 dist/OfficePcAudit.exe입니다. 같은 폴더의 .exe.config와 함께 실행합니다. 인터넷·NuGet·추가 PowerShell 모듈 없이 Windows 기본 C# 컴파일러를 사용합니다. ./package.ps1은 테스트 후 배포버전/1.0.0과 ZIP을 생성합니다. EXE는 코드서명하지 않았습니다.

## 판정과 제한

- 통과 / 부분통과 / 조치 필요 / 수동 확인 필요 / 확인 불가를 구분합니다.
- MS 계정 연결 확인은 부분통과입니다. 계정의 인증 수단·복구 정보·최근 로그인 활동은 수동으로 검토하고 의견에 기록합니다. 부분통과는 통과 건수에 합산하지 않습니다.
- 조회 오류·권한 부족·시간 초과를 통과로 처리하지 않습니다.
- 로컬 암호 정책을 확인하며 실제 암호 길이나 계정 전체의 안전성을 증명하지 않습니다.
- Windows 지원기간과 점검 수치는 내장 기준입니다. 업데이트 설치 최신성·침해 부재·법적 적합성·보안 인증을 보증하지 않습니다.
- 기관별 백신·백업·계정 기준을 포함하므로 도입 전 자체 기준과 비교하십시오.

## 보고서와 저장소

보고서는 저장 확인 후 실행 폴더의 결과출력에 새 HTML로 생성됩니다. PC 이름·로그인 계정·입력한 이름·보안 설정이 포함되므로 외부에 공개하지 마십시오. 네트워크 공유와 동기화 폴더 밖에서 사용하십시오.

Git에는 소스·테스트·빌드 및 패키징 스크립트·문서·가상 예시만 포함합니다. old/는 과거 작업물 보관용이며 실제 보고서가 있을 수 있습니다. old/, dist/, 배포버전/, 실제 보고서와 ZIP은 Git에서 제외합니다. 강제 추가(git add -f)하지 마십시오. 배포 ZIP은 소스에서 새로 빌드한 허용 파일만 넣습니다.
