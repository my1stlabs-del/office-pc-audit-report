3. 자동 업데이트 설정 수동 확인 필요

1. 조치 방법

1) 시작 → 설정 → Windows Update를 엽니다. 일시 중지 중이면 '업데이트 계속'을 누릅니다. 2) Windows Pro라면 시작에서 gpedit.msc를 검색해 실행 → 컴퓨터 구성 → 관리 템플릿 → Windows 구성 요소 → Windows 업데이트 → 최종 사용자 환경 관리 → '자동 업데이트 구성'을 엽니다. '사용'을 선택하고 옵션 '4 - 자동으로 다운로드하고 설치를 예약'을 적용합니다. 3) Home이라 정책 편집기가 없거나 '조직에서 관리'가 보이면 업데이트를 끈 프로그램·회사 관리 정책을 담당자에게 확인받으세요. '최신 업데이트가 제공되는 즉시 받기' 스위치는 기본 자동 보안 업데이트의 ON/OFF 스위치가 아닙니다. 4) 다시 점검합니다. 서비스 시작 방식이 Manual이거나 잠시 Stopped인 것만으로 OFF는 아닙니다.

1) Windows 키+R → msinfo32 입력 → Enter → '시스템 요약'에서 BIOS 모드와 보안 부팅 상태를 확인합니다. 2) 담당자와 복구키·백업을 확인한 뒤, 설정 → 시스템 → 복구 → 고급 시작 옵션의 '지금 다시 시작' → 문제 해결 → 고급 옵션 → UEFI 펌웨어 설정으로 들어갑니다. 저장하지 않은 문서는 먼저 저장하세요. 3) 기종 설명서에 따라 Secure Boot를 Enabled로 바꾸고 저장합니다. 메뉴 위치는 제조사마다 다릅니다. BIOS 모드가 레거시이거나 옵션을 찾지 못하면 담당자에게 맡기세요. CSM·디스크 형식을 임의로 바꾸거나 보안 부팅 키를 삭제하지 마세요. 4) Windows가 다시 켜지면 재점검합니다.

2. 항목의 의미

PC가 켜질 때 신뢰할 수 있는 부팅 프로그램인지 확인하는 기능입니다. 악성 부팅 프로그램을 막는 데 쓰이며, 설정을 잘못 바꾸면 Windows가 시작되지 않을 수 있습니다.

3. 자세히

영역부팅 보안
확인된 값가상 확인값: 실제 PC에서 조회하지 않았습니다.
판단 기준UEFI Secure Boot 활성 권장. 부재는 수동 확인 필요.
조치 권고장비 지원·부팅 구성을 확인한 후 담당자가 검토하십시오. BIOS 설정을 자동 변경하지 않습니다.

19. TPM 상태 수동 확인 필요

1. 조치 방법

1) Windows 키+R → tpm.msc 입력 → Enter. 'TPM을 사용할 준비가 되었습니다'와 사양 버전 2.0인지 확인합니다. 2) TPM을 찾지 못하면 담당자가 제조사 안내에 따라 UEFI에서 Intel PTT, AMD fTPM 또는 Security Device Support를 켭니다. 진입 경로는 설정 → 시스템 → 복구 → 고급 시작 옵션 → 문제 해결 → 고급 옵션 → UEFI 펌웨어 설정입니다. 3) 준비되지 않음·오류가 보이면 그 문구를 담당자에게 전달합니다. 'TPM 지우기'나 초기화는 누르지 마세요. 암호화 자료·로그인에 영향을 줄 수 있습니다. 4) 변경·재시작이 끝나면 이 프로그램을 관리자 권한으로 실행해 재점검합니다.

2. 항목의 의미

TPM은 암호화 키 같은 중요한 보안 정보를 보호하는 장치입니다. 장치가 있다는 것과 Windows에서 사용할 준비가 끝났다는 것은 다릅니다.

3. 자세히

확인된 값가상 확인값: 실제 PC에서 조회하지 않았습니다.
판단 기준TPM 2.0 및 현재 준비 완료는 통과. 미존재·구버전·준비 미완료는 조치 필요.

8. 점검 방법과 한계

  • 프로그램이 직접 사용하는 조회는 로컬 Windows API·WMI·COM·읽기 전용 레지스트리입니다. 인터넷 검색·업데이트 검색·원격 접속·설정 변경·자동 권한 상승을 구현하지 않았습니다. 이 보고서는 실행 중 통신을 계측한 증명서는 아닙니다.
  • 현재 실행 계정에 허용된 정보를 조회합니다. TPM·암호화 상세 조회에는 관리자 권한이 필요할 수 있습니다. 공급자 오류·권한 부족·15초 조회 시간 초과는 확인 불가로 처리합니다. 시간 초과한 운영체제 조회가 즉시 취소된다고 보장하지 않습니다.
  • Windows Update는 로컬 QFE 기록 일부만 조회합니다. 최신 보안 업데이트 적용 여부, ESU 가입·유효성, 서버의 최신 버전과 비교하지 않았습니다.
  • Defender 외 제품의 등록 정보는 실제 설치·라이선스·정의 최신성을 보장하지 않습니다. 타사 백신의 업무용 사용 승인은 별도 확인 사항입니다.
  • 로컬 계정 정책은 현재 암호의 안전성이나 Windows Hello·Microsoft 계정 정책을 증명하지 않습니다. 도메인·MDM 정책의 전체 적용 결과는 검증하지 않았습니다.
  • 개인정보 파일 내용·파일 목록·암호·인증 토큰·브라우저 기록·제품키·하드웨어 일련번호·IP·MAC 주소는 수집하지 않습니다. 보고서에는 PC 이름·로그인 계정·직접 입력한 이름 등 내부 정보가 포함됩니다.
  • 쓰기 허용 범위는 사용자가 요청한 결과출력 폴더와 HTML 보고서입니다. Windows·런타임·백신이 남기는 부수 기록과 사용자가 브라우저에서 인쇄·저장하는 PDF는 프로그램의 직접 쓰기 제한 범위 밖입니다.
  • 저장 HTML은 편집 가능한 파일입니다. 전자서명·위변조 방지 기능이 없으므로 공식 보관본은 조직의 문서관리 절차에 따라 보관하십시오.
