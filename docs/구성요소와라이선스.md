# 구성요소와 라이선스

배포 버전: 1.0.0 / Windows x64 / 2026-11-07.

|구성요소|출처·버전|용도·배포|
|---|---|---|
|이 프로젝트의 C# 소스|src/ 자체 작성|GUI, 조회, 판정, HTML 생성, 저장 경계. 제3자 소스 코드를 복사하지 않았으며 사용자용 프로젝트 소스로 제공. 별도의 공개 오픈소스 라이선스를 임의 부여하지 않음|
|.NET Framework|Microsoft, 실행 요구 4.8|System, System.Core, System.Management, System.Drawing, System.Windows.Forms, Microsoft.CSharp. 운영체제 설치본을 참조하며 DLL을 배포하지 않음. Microsoft 소프트웨어 라이선스 적용|
|Windows API·COM·WMI|Microsoft Windows 10/11 제공|kernel32, advapi32, netapi32, wscapi 및 Windows 공급자. 별도 DLL 재배포 없음. Windows 라이선스 적용|
|맑은 고딕|Windows 설치 글꼴|GUI와 보고서 CSS에서 이름으로 참조. 글꼴 파일을 복사·포함하지 않음|
|C# 컴파일러|이 환경의 Microsoft C# 4.8.9221.0 (C# 5)|빌드 전용. 배포 패키지에 포함하지 않음|

실행 프로그램에 NuGet·Python·웹 프레임워크·타사 문서 생성 라이브러리·분석 SDK·업데이트 SDK를 추가하지 않았습니다. 직접 PDF 생성이나 Word 자동화도 없습니다.

개발 중 첨부 문서 검토·레이아웃 검증에 사용한 도구(pypdf, Pillow, pypdfium2, Playwright, 설치된 Edge 등)는 개발 환경의 도구일 뿐 EXE나 배포 ZIP의 구성요소가 아닙니다.

실행 파일은 코드서명하지 않았습니다. 별도 유료 서비스·라이선스 서버 접속은 없습니다. 앱이 사용하는 Windows/.NET 구성요소의 사용조건은 해당 Microsoft 제품 약관을 따릅니다.
