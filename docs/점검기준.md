# 점검 기준과 로컬 조회 경로

기준 1.0.0 / 2026-11-07. 소규모 Windows Home 사무실용 내부 기준이며 인증·법적 적합성 기준이 아닙니다. 기준 수치는 실행 파일에 내장되어 자동 업데이트되지 않습니다. 시스템 시계를 사용합니다.

통과·조치 필요은 아래에 적힌 제한된 기준에만 적용합니다. 권한 부족·공급자 오류·15초 제한시간 초과는 확인 불가입니다. 판정은 통과 / 부분통과 / 조치 필요 / 수동 확인 필요 / 확인 불가 5개입니다. 조회 성공 후 정보 부재는 수동 확인 필요이며, 확인 불가는 조회·유효값 읽기 실패에만 사용합니다. 정책이 미설정이라는 이유만으로 기능이 꺼졌다고 단정하지 않습니다.

## 기본 정보

호스트명과 로그인 사용자명은 환경 API, 제조사·모델·RAM은 Win32_ComputerSystem, CPU 모델·아키텍처는 Win32_Processor, OS 이름·빌드·설치일은 Win32_OperatingSystem, 드라이브 용량은 GetDiskFreeSpaceEx, 펌웨어는 GetFirmwareType으로 조회합니다. WMI는 명시적 필드만 SELECT하며 원격 호스트를 입력할 수 없습니다.

## 정책 적용 범위

Windows Home 독립 PC의 로컬 설정 조회가 기본입니다. 화면보호기의 사용자 정책을 사용자 기본 설정보다 우선합니다. 도메인·MDM 정책의 전체 유효 결과, 절전 후 잠금·Windows Hello 등 모든 로그인 경로를 완전 평가하지 않습니다. 이들에 영향을 받는 값은 수동 확인 필요 또는 제한 설명을 남깁니다.

## 수동 항목

개인정보 파일 정리, 파일 암호화·접근 제한, 백업·복구, 퇴사자·권한 정리, 암호 관리, 공유·원격접속 필요성, 타사 백신 승인·라이선스, 사고·의심 증상을 직원이 응답합니다. 화면 초기값은 모두 ‘미응답’이며 자동 결과 건수에 합산하지 않습니다. USB 제한 정책 자체는 자동 조치 필요 항목에서 제외했습니다.

## Microsoft 계정 부분통과 검토

부분통과는 계정 유형만 확인했다는 뜻이며 보안 기준 충족의 승인이 아닙니다. 담당자는 2단계 인증 또는 패스키 등 인증 수단, 복구 정보, 최근 로그인 활동을 확인합니다. 충분하면 검토 의견에 확인일과 결과를 기록하고, 미흡하면 보완하며 미확인이면 검토를 유지합니다. 자동 판정은 그대로 유지하며 암호·인증 코드·복구 코드를 수집하지 않습니다.

Microsoft 계정 보안 안내: https://support.microsoft.com/en-us/accounts-billing/manage/how-to-help-keep-your-microsoft-account-secure
