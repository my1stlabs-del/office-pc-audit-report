# 1.0.0 검증 결과와 제한

검증일: 2026-11-07. 기존 개발 이력을 정리한 첫 Git 공개 준비 버전입니다. 과거 배포본과 개발 문서는 old에 보관하며 Git 대상에서 제외합니다.

## 이번 버전 확인

- Windows x64 빌드 성공, 자동 테스트 138개 통과.
- MS 계정은 연결 여부만 확인하므로 부분통과로 표시. 통과와 건수를 분리하고 우선 검토 및 상세에 유지합니다.
- 부분통과 레이블·판정·별도 집계·상세 유지·수동 검토 안내를 회귀 검사합니다.
- 기존 조회·중단·시간 초과·파일 저장 경계·HTML 인코딩·보고서 구조 검사를 유지합니다.
- 소스 쓰기 경계 검사는 위험 API와 읽기 전용 설정을 검사하는 보조 정적 검사이며 완전한 보안 증명은 아닙니다.
- 저장소 검사는 Git 공개 후보의 경로 허용 목록과 일부 비밀값 패턴을 검사합니다. 실제 PC 보고서·배포 파일·old 보관물은 제외합니다. 모든 개인정보 탐지를 보장하지 않습니다.
- 배포 스크립트는 새 빌드와 허용 문서만 묶으며 기존 배포 폴더에서 복사하지 않습니다. 결과출력이나 old를 포함하지 않습니다.

## 검증 범위와 미실시 항목

이번 버전은 로컬 빌드·자동 테스트로 확인했습니다. 과거 개발 중 Windows 11 Home ARM64의 x64 에뮬레이션과 Windows 11 Pro Intel x64 실제 조회·GUI를 확인한 기록이 있으나, 이를 이번 변경의 전체 실장비 재검증으로 간주하지 않습니다.

Windows 10·AMD x64·전체 DPI 배율·타사 백신 전환·Microsoft 계정 연결 전환과 온라인 보안 설정 비교는 이번 버전에서 실장비 검증하지 않았습니다. 실제 계정의 2단계 인증·패스키·복구 정보·로그인 활동은 조회하지 않습니다.

ETW/Procmon 수준의 네트워크·파일·레지스트리 전체 계측 검증은 미실시입니다. 내부 Windows 공급자의 동작을 정적 소스 검사만으로 보증하지 않습니다. 보고서는 편집 가능한 HTML이며 전자서명이나 위변조 방지 기능이 없습니다.

## 보고서 시각 검증의 남은 제한

가상 HTML을 재생성하고 부분통과 집계·상세·HTML 구조는 자동 테스트로 확인했습니다. 이번 환경에서 Edge headless의 원격 디버깅 파이프 연결과 CDP 연결이 실패해 최신 화면 및 A4 인쇄 배치의 이미지 검증은 완료하지 못했습니다. 공개 소스 준비와 별개로 실사용 배포 전 브라우저에서 가상 예시의 화면·인쇄 미리보기를 확인해야 합니다.
