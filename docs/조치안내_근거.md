# 조치 안내 근거 (1.0.0)

19개 항목을 조치 방법 → 쉬운 의미 → 기존 상세 정보 순서로 표시합니다.
명령은 문서로만 제공하며 앱에서 자동 실행하지 않습니다. 관리자 권한 실행법, 재점검 방법, Home/Pro 차이와 해당 조치에 필요한 주의를 함께 표시합니다.
GUI 이름은 Windows 버전·표시 언어·관리 정책에 따라 다를 수 있습니다.
