업무용 PC 보안점검 도구 1.0.0

1. 실행
- 배포 ZIP을 일반 로컬 폴더에 모두 압축 해제하고 OfficePcAudit.exe를 실행합니다.
- EXE와 OfficePcAudit.exe.config를 같은 폴더에 두십시오.
- Windows 10/11 x64 및 .NET Framework 4.8이 필요합니다. Windows 10 22H2와 Windows 11에는 기본 포함됩니다.
- Python, Office, PowerShell 모듈, 계정 가입은 필요하지 않습니다.
- 일반 조회는 일반 권한으로 가능합니다. TPM·암호화 상세 조회에는 관리자 권한이 필요할 수 있습니다. 프로그램은 자동 상승을 요청하지 않습니다.
- 실행 파일은 전자서명하지 않았습니다. Windows 또는 백신에서 출처 확인 경고가 나올 수 있습니다.

2. 4단계 화면으로 점검
- 1단계 점검 안내: 조회 범위와 보고서에 기록되는 정보를 읽고 ‘자동 확인으로’를 누릅니다.
- 2단계 자동 확인: ‘점검 시작’을 눌러 기본 정보와 19개 자동 항목을 조회합니다.
- 진행 중에는 이동을 막고 중단 버튼을 제공합니다. 중단 시 대기를 빠르게 끝내지만 Windows 내부 조회의 즉시 종료는 보장하지 않습니다.
- 조회마다 최대 15초 대기하며 WMI 조회 자체에도 8초 제한이 있습니다. 공급자가 제한 시간을 무시할 수 있습니다.
- 시간 초과·중단 후 내부 조회가 남으면 새 조회를 시작하지 않아 작업 누적을 방지합니다. 해당 항목은 확인 불가로 표시합니다. 잠시 후 다시 점검하거나 프로그램을 재실행하십시오.
- 자동 확인 완료 후 결과와 조치 안내를 살펴보고 ‘수동 확인으로’를 직접 누릅니다.
- 중단·실패 상태에서는 다음 단계 및 저장을 차단하며 다시 점검할 수 있습니다.
- 3단계 수동 확인: 8개 질문에 응답합니다. ‘선택해 주세요’는 미응답이며 ‘모름’과 구분됩니다. 미응답도 그대로 기록할 수 있습니다.
- 4단계 정보 입력 및 출력: 기관명·점검자·실제 PC 사용자, 검토 의견·후속 조치를 입력합니다.
- 이전/다음으로 이동해도 자동 결과·수동 응답·입력값은 유지됩니다. 다시 점검하면 확인 후 자동 결과만 교체합니다.
- 저장 전 미응답 개수와 미입력 이름 항목을 안내합니다. 누락이 있어도 확인 후 저장할 수 있습니다.
- 암호·개인정보 파일 내용·인증 토큰을 입력하지 마십시오.

3. 저장과 인쇄
- HTML 보고서 저장을 누른 뒤 표시되는 이름·저장 위치를 확인하고 저장합니다.
- 취소를 누르면 결과출력 폴더도 생성하지 않습니다.
- 저장 위치는 EXE가 있는 폴더의 결과출력으로 고정됩니다. 임의 경로는 지정할 수 없습니다.
- 파일명: PC보안점검_PC이름_YYYYMMDD_HHMMSS_고유값.html
- 같은 이름을 덮어쓰지 않고 매번 새 파일을 만듭니다.
- 결과출력 폴더의 HTML을 Edge/Chrome으로 열고 Ctrl+P를 누릅니다.
- A4, 배율 기본값, 필요에 따라 머리글·바닥글을 끄고 인쇄하거나 PDF로 저장합니다.
- PDF 저장과 브라우저 기록은 브라우저가 수행하며 이 프로그램의 쓰기 제한 범위 밖입니다.
- 보고서 HTML에는 외부 글꼴·이미지·스크립트·웹 서버가 필요하지 않습니다.

4. 저장이 안 될 때
- 프로그램을 Program Files, 네트워크 공유, OneDrive 등 동기화 폴더 밖의 쓰기 가능한 로컬 폴더에 압축 해제하십시오.
- 다른 위치로 연결되는 폴더(심볼릭 링크·정션·재분석 지점)는 차단합니다. 상위 경로에도 적용합니다.
- 디스크 공간과 폴더 권한을 확인한 후 다시 저장합니다. 관리자 실행을 먼저 시도하지 마십시오.
- 저장 실패 시 불완전한 HTML이 결과출력에 남을 수 있습니다. 프로그램은 파일을 자동 삭제하지 않습니다.
- 일부 동기화 폴더는 일반 폴더처럼 보여 자동 검출할 수 없습니다. 폴더가 동기화되지 않는지 직접 확인하십시오.

5. 결과 해석
- 통과: 해당 항목에 적힌 제한된 기준을 충족함.
- 조치 필요: 해당 내부 기준을 충족하지 못함.
- 부분통과: MS 계정 유형만 확인. 계정 보안 수동 검토가 남아 있으며 통과 건수와 별도입니다.
- 수동 확인 필요: 값은 조회했으나 업무상 승인·실제 동작 확인 또는 추가 판단이 필요함.
- 확인 불가: 권한 부족·공급자 오류·유효값 조회 실패·시간 초과로 조회하지 못함.
- 통과가 PC 전체의 안전을 보증하지 않습니다. 점수는 계산하지 않습니다.
- Windows 10 Home/Pro는 ESU를 검사하지 않고 조직 운영기준 미충족으로 표시합니다.
- 타사 백신 등록은 비용·승인 확인 대상이며 유료·불법 사용이라고 단정하지 않습니다.
- 정책상 암호 길이는 실제 암호·PIN의 강도를 증명하지 않습니다. 실제 암호는 검사하지 않습니다.
- 자동 결과는 직접 바꾸지 않습니다. 예외·승인 사유는 검토 의견에 기재합니다.

6. 정보와 동작 범위
- 메모리의 정보는 종료 시 더 이상 유지하지 않습니다. 보안 삭제를 보장하는 의미는 아닙니다.
- 보고서에는 PC 이름·계정·관리자 구성·입력한 이름 등 내부 정보가 있으므로 관리에 주의하십시오.
- 제품키, 일련번호, IP/MAC, 브라우저 기록, 개인 문서 내용/목록, 암호를 수집하지 않습니다.
- 앱이 직접 쓰는 파일은 명시적으로 저장한 결과출력 내 HTML뿐입니다. 폴더 생성도 저장 시에만 합니다.
- Windows·런타임·백신의 실행 기록까지 없다고 보장하지 않습니다.
- 원격 지원·네트워크 검색·자동 업데이트·설정 변경·백신 검사·자동 수정 기능이 없습니다.
- 인터넷 비사용은 코드 설계 범위입니다. 실행 중 통신과 OS 공급자 부수 동작의 완전한 계측 검증은 별도입니다.
- 보고서는 편집 가능한 HTML이며 위변조 방지·전자서명·보안 인증 기능은 없습니다.

문의·검토 시 기준 버전과 해당 항목의 판정·확인된 값·오류 종류를 확인하십시오.






12번: Windows 로그인 MS 계정은 부분통과입니다. 2단계 인증 또는 패스키 등 인증 수단, 복구 정보, 최근 로그인 활동을 직접 확인해 검토 의견에 확인일과 결과를 남기십시오. 충분하면 검토 완료로 기록하고 미흡하면 보완하며 미확인이면 검토를 유지합니다. 자동 판정은 변경하지 않습니다. 로컬 계정은 최소 암호 길이 정책 12자 이상 통과이며 실제 암호 길이는 검사하지 않습니다. 암호·인증 코드·복구 코드는 입력하지 마십시오.
