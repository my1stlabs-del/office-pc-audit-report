1. Windows 지원 상태
1. 조치 방법
1) 시작 → 설정 → Windows Update → '업데이트 확인'을 누릅니다.
2) 지원 중인 Windows 버전으로의 기능 업데이트가 표시되면 업무 자료를 백업한 뒤 설치합니다. 재시작 전에 작업 중인 문서를 저장하세요.
3) Windows 10이거나 업그레이드가 제공되지 않으면 담당자에게 Windows 11 전환 가능 여부를 요청하세요. 단순 재시작만으로 지원 종료가 해결되지는 않습니다.

2. 항목의 의미
Windows에도 보안 수리를 받을 수 있는 기간이 있습니다. 그 기간이 끝난 버전은 새로 발견되는 문제를 고치지 못할 수 있습니다.

3. 자세히
기준: Home/Pro 내장 수명 주기표. Windows 10은 조직 운영기준상 조치 필요.
기존 권고: 지원 중인 Windows 버전으로 전환을 검토하십시오. ESU 예외는 담당자가 별도 검토하십시오.
조회 방법: HKLM CurrentVersion: EditionID, DisplayVersion, CurrentBuildNumber


2. 최근 보안·누적 업데이트 기록
1. 조치 방법
1) 시작 → 설정 → Windows Update → '업데이트 확인'을 누릅니다.
2) 보안·누적 업데이트를 다운로드하고 설치합니다. '다시 시작 필요'가 나오면 문서를 저장하고 재시작합니다.
3) 같은 화면의 '업데이트 기록'에서 설치 성공 여부를 확인한 뒤 이 프로그램으로 다시 점검합니다. 오류가 반복되면 오류 코드를 담당자에게 전달하세요.

2. 항목의 의미
보안 업데이트는 Windows의 허점을 고치는 수리입니다. 이 항목은 PC에 남은 설치 기록이 오래됐는지 확인합니다. 통과해도 모든 최신 업데이트가 설치됐다는 뜻은 아닙니다.

3. 자세히
기준: 로컬 QFE에서 분류 가능한 최근 업데이트 설치 후 45일 이내. 최신성 보장 아님.
기존 권고: Windows Update 화면에서 설치 기록과 미설치 업데이트를 직접 확인하십시오. 점검 도구는 업데이트 검색·설치를 하지 않습니다.
조회 방법: 로컬 WMI Win32_QuickFixEngineering: HotFixID, Description, InstalledOn


3. 자동 업데이트 설정
1. 조치 방법
1) 시작 → 설정 → Windows Update를 엽니다. 일시 중지 중이면 '업데이트 계속'을 누릅니다.
2) Windows Pro라면 시작에서 gpedit.msc를 검색해 실행 → 컴퓨터 구성 → 관리 템플릿 → Windows 구성 요소 → Windows 업데이트 → 최종 사용자 환경 관리 → '자동 업데이트 구성'을 엽니다. '사용'을 선택하고 옵션 '4 - 자동으로 다운로드하고 설치를 예약'을 적용합니다.
3) Home이라 정책 편집기가 없거나 '조직에서 관리'가 보이면 업데이트를 끈 프로그램·회사 관리 정책을 담당자에게 확인받으세요. '최신 업데이트가 제공되는 즉시 받기' 스위치는 기본 자동 보안 업데이트의 ON/OFF 스위치가 아닙니다.
4) 다시 점검합니다. 서비스 시작 방식이 Manual이거나 잠시 Stopped인 것만으로 OFF는 아닙니다.

2. 항목의 의미
Windows가 업데이트를 자동으로 챙기도록 설정했는지 확인합니다. 자동 기능이 켜진 것과 실제 최신 패치 설치가 끝난 것은 다릅니다.

3. 자세히
기준: 자동 업데이트 설정 활성 통과, 명시적 비활성 조치 필요. 실제 설치 최신성은 별도 항목.
기존 권고: Windows Update에서 자동 업데이트 설정을 확인하십시오. 이 점검은 검색·다운로드·설치를 실행하지 않습니다.
조회 방법: NoAutoUpdate 정책; Microsoft.Update.AutoUpdate.Settings.NotificationLevel (읽기 전용)


4. Defender 실행·실시간 보호
1. 조치 방법
1) 시작에서 'Windows 보안' 검색 → 바이러스 및 위협 방지 → '설정 관리'를 엽니다.
2) Microsoft Defender를 사용하는 PC라면 '실시간 보호'를 켭니다. 꺼짐 오류가 계속되면 재시작 후 담당자에게 문의하세요.
3) 회사가 승인한 다른 백신을 사용한다면 그 백신 화면에서 보호 상태를 확인합니다. Defender를 켜려고 다른 백신을 임의로 삭제하지 마세요.

2. 항목의 의미
빠른 검사·전체 검사 최근 완료 시각도 자세히에 표시합니다. 기록이 없거나 조회가 막히면 별도로 안내합니다. 시각 표시만으로 최근 검사 기준 충족이나 감염 없음을 판정하지 않습니다. 백신이 파일과 프로그램을 실시간으로 살펴보는지 확인합니다. 다른 백신이 대신 보호하는 PC에서는 Defender가 꺼져 있을 수 있습니다.

3. 자세히
기준: Defender 서비스·백신·실시간 보호 활성. 타사 보호 사용 여부와 구분.
기존 권고: Windows 보안에서 활성 백신과 실시간 보호를 확인하십시오. 타사 백신을 먼저 삭제하지 마십시오.
조회 방법: 로컬 WMI MSFT_MpComputerStatus (서비스·실시간 보호, QuickScanEndTime, FullScanEndTime); WscGetSecurityProviderHealth(ANTIVIRUS)


5. Defender 정의 업데이트 시각
1. 조치 방법
1) 시작 → Windows 보안 → 바이러스 및 위협 방지 → '보호 업데이트'를 엽니다.
2) '업데이트 확인'을 눌러 최신 보안 인텔리전스를 받습니다. 인터넷 연결이 필요합니다.
3) 업데이트가 끝나면 다시 점검합니다. 다른 백신을 쓰는 경우 그 제품의 업데이트 메뉴에서 확인하세요.

2. 항목의 의미
백신이 악성코드를 알아보는 데 쓰는 정보를 얼마나 최근에 받았는지 확인합니다. 백신이 켜져 있어도 이 정보가 오래되면 새 악성코드를 놓칠 수 있습니다.

3. 자세히
기준: 3일 이내 통과, 3일 초과~7일 수동 확인 필요, 7일 초과 조치 필요. 비활성 Defender는 별도 확인.
기존 권고: 활성 백신의 정의 업데이트를 확인하십시오. 이 프로그램은 업데이트나 검사를 실행하지 않습니다.
조회 방법: 로컬 WMI MSFT_MpComputerStatus.AntivirusSignatureLastUpdated


6. 타사 백신 사용 승인·라이선스
1. 조치 방법
1) 시작 → Windows 보안 → 설정 → '공급자 관리'에서 사용 중인 백신 이름을 확인합니다.
2) 담당자에게 이 제품을 회사에서 사용해도 되는지, 업무용 라이선스가 유효한지 확인받습니다. 제품 안의 구독·라이선스 화면도 확인하세요.
3) 승인된 제품이면 검토 의견에 제품명과 확인 내용을 적습니다. 등록 목록만 보고 임의로 삭제하지 마세요.

2. 항목의 의미
Windows 기본 백신 외 제품이 회사에서 승인되고 사용권도 갖춰졌는지 확인하는 항목입니다. 제품 이름만으로 유료·불법 사용을 판단할 수 없습니다.

3. 자세히
기준: 타사 제품 등록 시 사용 승인·업무용 라이선스 수동 확인 필요. 설치만으로 유료·무단 사용을 단정하지 않음.
기존 권고: 제품명과 업무용 이용조건을 담당자가 확인하십시오. 승인된 제품은 검토 의견에 사유를 남기십시오.
조회 방법: 로컬 WMI root SecurityCenter2 AntiVirusProduct.displayName (파일 경로·프로세스 실행 없음)


7. Windows 방화벽 프로필
1. 조치 방법
1) 시작 → Windows 보안 → '방화벽 및 네트워크 보호'를 엽니다.
2) '도메인 네트워크', '개인 네트워크', '공용 네트워크'를 각각 열고 Microsoft Defender 방화벽을 켭니다. 관리자 승인이 나오면 승인합니다.
3) 업무 프로그램의 연결이 막히면 방화벽 전체를 끄지 말고 담당자에게 해당 프로그램만 허용해 달라고 요청하세요.

2. 항목의 의미
방화벽은 PC로 들어오고 나가는 통신을 거르는 문지기입니다. 지금 쓰지 않는 네트워크 종류도 나중에 연결할 수 있어 세 종류를 모두 확인합니다.

3. 자세히
기준: 도메인·개인·공용 세 프로필 모두 활성화.
기존 권고: Windows 보안에서 꺼진 프로필과 업무상 예외를 검토하십시오.
조회 방법: 로컬 COM HNetCfg.FwPolicy2: FirewallEnabled, CurrentProfileTypes (조회 전용)


8. 원격 데스크톱
1. 조치 방법
1) 시작 → 설정 → 시스템 → '원격 데스크톱'을 엽니다.
2) 외부에서 이 PC에 접속할 업무가 없으면 원격 데스크톱을 끕니다.
3) 업무에 꼭 필요하면 담당자에게 승인·접속 가능한 사용자·접속 경로를 확인받고 검토 의견에 적습니다. Home에서 메뉴가 없으면 기본 호스트 미지원입니다. 별도 원격지원 프로그램은 이 항목에서 검사하지 않습니다.

2. 항목의 의미
다른 PC에서 이 PC의 화면과 키보드를 원격으로 조작할 수 있게 하는 기능입니다. 필요 없이 열어 두면 접속 시도의 대상이 될 수 있습니다.

3. 자세히
기준: 기본 비활성 권장. 활성화는 업무 필요성 확인. 타사 원격 도구는 조사하지 않음.
기존 권고: 필요한 원격접속만 승인하고 계정·접근 범위를 확인하십시오.
조회 방법: HKLM SYSTEM CurrentControlSet Control Terminal Server.fDenyTSConnections; EditionID


9. SMBv1 선택 기능
1. 조치 방법
1) 오래된 복합기·파일서버와 연결해 쓰는지 담당자에게 먼저 확인합니다.
2) 시작에서 'Windows 기능 켜기/끄기' 검색 → 실행 → 'SMB 1.0/CIFS 파일 공유 지원' 체크를 해제 → 확인 → 안내에 따라 재시작합니다.
[PowerShell 대안] 아래 명령을 관리자 PowerShell에서 실행할 수 있습니다. 문서를 저장하고 이후 직접 재시작하세요.
[관리자 PowerShell 여는 법] 시작 버튼을 누르고 Windows PowerShell을 검색 → 마우스 오른쪽 클릭 → '관리자 권한으로 실행' → '예'.
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol -NoRestart
3) 공유 장비 연결이 안 되면 기능을 무작정 다시 켜지 말고 장비의 최신 연결 방식 지원을 확인하세요.

2. 항목의 의미
아주 오래된 파일 공유 방식입니다. 보안상 약점이 있어, 구형 장비 때문에 꼭 필요한 경우가 아니라면 꺼 두는 편이 좋습니다.

3. 자세히
기준: SMB1Protocol 비활성 또는 제거 상태.
기존 권고: 구형 장비 의존성을 확인한 후 담당자가 SMBv1 비활성화를 검토하십시오.
조회 방법: 로컬 WMI Win32_OptionalFeature(Name=SMB1Protocol).InstallState


10. 공유폴더 존재
1. 조치 방법
1) Windows 키와 R을 함께 누르고 fsmgmt.msc 입력 → Enter → 왼쪽 '공유'를 누릅니다. 열리지 않으면 관리자 계정으로 담당자에게 확인을 요청하세요.
2) 이 프로그램의 '일반 디스크 공유' 이름과 목록을 비교합니다. 불필요한 일반 공유를 마우스 오른쪽 클릭 → '공유 중지'를 선택합니다. 다른 직원이 사용 중인지 먼저 확인하세요.
3) 필요한 공유는 담당자가 공유 권한과 폴더의 보안 권한을 함께 검토합니다. ADMIN$, C$, IPC$ 같은 기본 관리 공유는 이 목록만 보고 중지하지 마세요.

2. 항목의 의미
공유폴더는 다른 PC가 내 PC의 폴더에 접속하게 하는 기능입니다. 공유가 있다는 사실보다 누가 어떤 파일을 볼 수 있는지가 중요합니다. 공유 중지는 원본 파일 삭제가 아닙니다.

3. 자세히
기준: 일반 디스크 공유가 있으면 업무 필요성 확인. 기본 관리 공유는 구분.
기존 권고: 공유 목적·접근 권한·개인정보 포함 여부를 확인하십시오. 이 도구는 공유 내용을 열거나 삭제하지 않습니다.
조회 방법: 로컬 WMI Win32_Share.Name, Type (공유 경로·폴더 내용 미수집)


11. Guest 계정
1. 조치 방법
1) 아래 관리자 명령창을 엽니다. 이름이 바뀌지 않은 기본 Guest 계정이라면 다음을 실행합니다.
[관리자 명령창 여는 법] 시작 버튼을 누르고 cmd를 입력 → '명령 프롬프트'를 마우스 오른쪽 클릭 → '관리자 권한으로 실행' → '예'. 아래 명령을 한 줄씩 입력한 뒤 Enter를 누릅니다.
net user Guest /active:no
2) '사용자 이름을 찾을 수 없습니다'가 나오면 계정 이름이 바뀌었을 수 있습니다. 자세히의 확인된 계정명을 담당자에게 보여 주고 기본 Guest 계정을 비활성화해 달라고 요청하세요.
3) 완료되면 다시 점검합니다. 사용하는 본인 계정을 임의로 끄지 마세요.

2. 항목의 의미
Guest는 임시 방문자용 기본 계정입니다. 사무실 PC에서는 쓰지 않는 이 계정을 비활성화해 불필요한 로그인 경로를 줄입니다.

3. 자세히
기준: 내장 Guest(SID 끝 -501) 비활성화.
기존 권고: 업무상 필요한지 확인하고 Guest 계정을 사용하지 않는 구성을 검토하십시오.
조회 방법: 로컬 WMI Win32_UserAccount(LocalAccount=TRUE): Name, SID, Disabled


12. 로그인 계정·암호 정책
1. 조치 방법
1) 시작 → 설정 → 계정 → '사용자 정보'에서 Windows 로그인 계정 유형을 확인합니다. Microsoft 계정은 계정 유형만 확인되어 부분통과입니다. account.microsoft.com/security에서 2단계 인증 또는 패스키 등 인증 수단, 복구 정보, 최근 로그인 활동을 직접 확인하고 검토 의견에 확인일과 결과를 기록합니다. 미흡하면 보완하고 미확인이면 검토를 유지합니다. 암호·인증 코드·복구 코드는 보고서에 적지 마세요. 이 항목 때문에 로컬 정책을 바꿀 필요는 없습니다.
2) 로컬 계정을 유지한다면 관리자 명령창에서 다음 명령을 실행합니다.
[관리자 명령창 여는 법] 시작 버튼을 누르고 cmd를 입력 → '명령 프롬프트'를 마우스 오른쪽 클릭 → '관리자 권한으로 실행' → '예'. 아래 명령을 한 줄씩 입력한 뒤 Enter를 누릅니다.
net accounts /minpwlen:12
3) '명령을 잘 실행했습니다'가 나오면 다시 점검합니다. 이 명령은 PC의 로컬 계정 암호 최소 길이 정책을 바꾸며, 기존 암호를 자동으로 길게 바꾸지는 않습니다.
4) 실제 암호도 바꾸려면 설정 → 계정 → 로그인 옵션 → 암호 → 변경에서 길고 고유한 암호를 정합니다. MS 계정으로 전환하려면 사용자 정보의 '대신 Microsoft 계정으로 로그인'을 사용합니다. Office·OneDrive 로그인만으로는 전환되지 않습니다.

2. 항목의 의미
Microsoft 계정 연결 확인은 계정 보안 충족의 증거가 아니므로 부분통과로 표시하고 수동 검토를 남깁니다. 로컬 계정은 새 암호의 최소 길이 정책 12자 이상을 확인합니다. 실제 암호 길이·안전성이나 온라인 계정 보안 설정은 자동 검사하지 않습니다.

3. 자세히
기준: Windows 로그인 MS 계정 확인은 부분통과이며 계정 보안 수동 검토가 필요합니다. 로컬 계정은 최소 암호 길이 정책 12자 이상 통과, 미달 조치 필요.
기존 권고: MS 계정은 2단계 인증 또는 패스키 등 인증 수단, 복구 정보, 최근 로그인 활동을 확인해 검토 의견에 기록하십시오. 미흡하면 보완하고 미확인이면 검토를 유지하십시오. 로컬은 최소 암호 길이 12자 이상을 검토하십시오. 암호·복구 코드·인증 코드를 이 도구에 입력하지 마십시오.
조회 방법: 현재 세션 WTS 사용자 + NetUserGetInfo(NULL, 24); 로컬은 NetUserModalsGet(NULL, 0)


13. 로컬 계정 잠금 정책
1. 조치 방법
1) 아래 관리자 명령창에서 다음 명령을 한 줄씩 실행합니다. 실패 집계 시간을 먼저 15분으로 줄이면 기존 잠금 시간이 더 길어도 설정 충돌을 줄일 수 있습니다.
[관리자 명령창 여는 법] 시작 버튼을 누르고 cmd를 입력 → '명령 프롬프트'를 마우스 오른쪽 클릭 → '관리자 권한으로 실행' → '예'. 아래 명령을 한 줄씩 입력한 뒤 Enter를 누릅니다.
net accounts /lockoutwindow:15 /lockoutduration:15
net accounts /lockoutthreshold:10
2) 첫 명령이 기존 정책과 충돌해 실패하면 먼저 'net accounts'로 현재 값을 확인하세요. Windows Pro에서는 시작에서 secpol.msc 실행 → 계정 정책 → 계정 잠금 정책에서 '실패 횟수 10회 / 잠금 기간 15분 / 집계 초기화 15분'을 함께 맞출 수 있습니다.
3) 다시 'net accounts'를 실행해 값이 반영됐는지 확인한 후 재점검합니다. 이 설정은 PC의 로컬 계정에 적용되며 MS 계정·PIN의 잠금 정책을 바꾸는 것은 아닙니다. 시험하려고 암호를 일부러 10번 틀리지 마세요.

2. 항목의 의미
누군가 암호를 계속 찍어 맞히려 할 때 로그인을 잠시 막는 설정입니다. 이 도구는 1~10회 실패 시 잠기고, 잠금이 15분 이상 이어지는지를 확인합니다.

3. 자세히
기준: 실패 1~10회, 잠금 15분 이상 또는 관리자 해제이면 통과. 미달 조치 필요. 로컬 계정 정책 범위.
기존 권고: 로컬 계정 정책을 검토하십시오. Windows Hello·Microsoft 계정 잠금은 이 값으로 판정하지 않습니다.
조회 방법: NetUserModalsGet(NULL, level 3)


14. 자동 로그인 설정
1. 조치 방법
1) Windows 키+R → netplwiz 입력 → Enter. 사용자 탭에 '사용자 이름과 암호를 입력해야 이 컴퓨터를 사용할 수 있음'이 보이면 체크 → 적용합니다.
2) 이 항목이 없거나 자동 로그인이 계속되면 담당자가 관리자 명령창에서 일반 Winlogon 자동 로그인을 다음과 같이 끌 수 있습니다. 현재 로그인은 바로 종료되지 않습니다.
[관리자 명령창 여는 법] 시작 버튼을 누르고 cmd를 입력 → '명령 프롬프트'를 마우스 오른쪽 클릭 → '관리자 권한으로 실행' → '예'. 아래 명령을 한 줄씩 입력한 뒤 Enter를 누릅니다.
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v AutoAdminLogon /t REG_SZ /d 0 /f
3) 문서를 저장하고 재시작한 뒤 암호·PIN·얼굴·지문 중 하나로 인증하는지 확인합니다. Sysinternals Autologon 같은 별도 도구를 사용했다면 담당자가 그 도구에서도 해제하세요. 저장된 암호나 비밀값을 직접 열어보지 마세요.

2. 항목의 의미
PC를 켰을 때 인증 없이 바탕화면까지 들어가는 설정입니다. 암호가 있어도 자동 로그인은 가능하므로, 암호 길이와는 별도로 확인합니다. PIN·얼굴·지문 인증은 자동 로그인과 다릅니다.

3. 자세히
기준: 일반 Winlogon 자동 로그인 미설정 또는 비활성은 통과. 다른 로그인 경로는 별도 확인.
기존 권고: 공유·분실 위험을 고려해 자동 로그인 필요성을 검토하십시오.
조회 방법: HKLM SOFTWARE Microsoft Windows NT CurrentVersion Winlogon.AutoAdminLogon만 조회


15. 시스템 드라이브 암호화
1. 조치 방법
1) 먼저 복구키를 본인 또는 담당자가 다시 찾을 수 있는지 확인합니다. 복구키를 이 보고서에 적지는 마세요.
2) 시작 → 설정 → 개인 정보 및 보안 → '장치 암호화'에서 켭니다. 메뉴가 없다면 시작에서 'BitLocker 관리' 검색 → 운영체제 드라이브(C: 등)의 'BitLocker 켜기'를 선택하고 복구키 백업 안내를 따릅니다.
3) 이미 암호화됐지만 보호가 일시 중지된 경우 'BitLocker 관리'에서 '보호 다시 시작'을 누릅니다. 진행 중이면 전원을 연결하고 완료될 때까지 기다린 뒤 재점검합니다.
4) 두 메뉴 모두 없거나 회사 관리 장비라면 담당자에게 지원 여부와 보관할 복구키 위치를 확인받으세요. 다른 사람의 PC에서 임의로 암호화를 시작하지 마세요.

2. 항목의 의미
PC나 저장장치를 잃어버렸을 때 안의 자료를 쉽게 읽지 못하게 하는 기능입니다. 암호화가 끝나도 보호가 일시 중지돼 있으면 보호 상태가 충분하지 않을 수 있습니다.

3. 자세히
기준: 보호 켜짐 및 암호화 완료 통과. 보호 꺼짐·변환 미완료 조치 필요. 공급자 미상 상태는 수동 확인.
기존 권고: 미암호화·보호 중지·진행 상태에 맞춰 담당자가 암호화를 검토하십시오. 복구키 보관은 별도 확인하며 키를 수집하지 않습니다.
조회 방법: Win32_EncryptableVolume.GetProtectionStatus / GetConversionStatus (상태 조회만)


16. 화면 자동 잠금
1. 조치 방법
1) 실제 PC 사용자의 계정에서 시작 → 설정 → 개인 설정 → 잠금 화면 → '화면 보호기'를 엽니다. 관리자용 다른 계정에서 설정하지 마세요.
2) 화면 보호기를 '(없음)' 대신 '빈 화면' 등으로 선택하고 '대기'를 10분 이하로 정합니다.
3) '다시 시작할 때 로그온 화면 표시'를 반드시 체크 → 적용 → 확인합니다.
4) 키보드·마우스를 건드리지 않고 정한 시간만큼 기다린 뒤, 다시 사용할 때 암호·PIN 등 인증이 필요한지 직접 확인합니다. 이후 재점검합니다. 모니터만 꺼지는 설정으로는 이 기준을 충족하지 않습니다. 자리를 비울 때는 Windows 키+L로 즉시 잠그세요.

2. 항목의 의미
자리를 비웠을 때 다른 사람이 내 PC를 사용하지 못하도록 자동으로 잠그는 기능입니다. 화면을 검게 만드는 것뿐 아니라 다시 사용할 때 인증도 요구해야 합니다.

3. 자세히
기준: 10분 이내 비활동 잠금 또는 인증 화면보호기 조건 충족 시 통과. 두 경로 모두 미달이면 조치 필요. 화면 꺼짐은 잠금으로 인정하지 않음.
기존 권고: 자동 잠금과 복귀 시 인증을 설정하고 자리를 비울 때 Win+L을 사용하십시오. 실제 잠금은 수동 시험하십시오.
조회 방법: HKLM Policies System.InactivityTimeoutSecs; HKCU 화면보호기 정책 + SystemParametersInfo GET 현재 화면보호기 상태


17. 사용자 계정 컨트롤(UAC)
1. 조치 방법
1) 시작에서 '사용자 계정 컨트롤 설정 변경'을 검색해 엽니다.
2) 막대를 맨 위 '항상 알림'으로 옮기거나, 기본값인 위에서 두 번째로 맞추고 확인 → 관리자 승인을 합니다. 화면을 어둡게 하지 않는 설정은 피하세요.
3) UAC 자체가 꺼져 있어 위 방법으로 해결되지 않으면 담당자가 관리자 명령창에서 다음을 실행하고 재시작합니다. 문서를 먼저 저장하세요.
[관리자 명령창 여는 법] 시작 버튼을 누르고 cmd를 입력 → '명령 프롬프트'를 마우스 오른쪽 클릭 → '관리자 권한으로 실행' → '예'. 아래 명령을 한 줄씩 입력한 뒤 Enter를 누릅니다.
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v EnableLUA /t REG_DWORD /d 1 /f
4) 재시작 후 1~2단계를 다시 적용하고 재점검합니다.

2. 항목의 의미
프로그램이 PC의 중요한 설정을 바꾸기 전에 '허용할까요?'라고 묻는 기능입니다. 실수나 악성 프로그램의 변경을 줄이는 데 도움이 됩니다.

3. 자세히
기준: EnableLUA=1, 관리자 승인 프롬프트 활성, 보안 데스크톱 사용.
기존 권고: UAC를 켜고 관리자 작업 시 승인 화면이 표시되는지 확인하십시오.
조회 방법: HKLM Policies System: EnableLUA, ConsentPromptBehaviorAdmin, PromptOnSecureDesktop


18. Secure Boot
1. 조치 방법
1) Windows 키+R → msinfo32 입력 → Enter → '시스템 요약'에서 BIOS 모드와 보안 부팅 상태를 확인합니다.
2) 담당자와 복구키·백업을 확인한 뒤, 설정 → 시스템 → 복구 → 고급 시작 옵션의 '지금 다시 시작' → 문제 해결 → 고급 옵션 → UEFI 펌웨어 설정으로 들어갑니다. 저장하지 않은 문서는 먼저 저장하세요.
3) 기종 설명서에 따라 Secure Boot를 Enabled로 바꾸고 저장합니다. 메뉴 위치는 제조사마다 다릅니다. BIOS 모드가 레거시이거나 옵션을 찾지 못하면 담당자에게 맡기세요. CSM·디스크 형식을 임의로 바꾸거나 보안 부팅 키를 삭제하지 마세요.
4) Windows가 다시 켜지면 재점검합니다.

2. 항목의 의미
PC가 켜질 때 신뢰할 수 있는 부팅 프로그램인지 확인하는 기능입니다. 악성 부팅 프로그램을 막는 데 쓰이며, 설정을 잘못 바꾸면 Windows가 시작되지 않을 수 있습니다.

3. 자세히
기준: UEFI Secure Boot 활성 권장. 부재는 수동 확인 필요.
기존 권고: 장비 지원·부팅 구성을 확인한 후 담당자가 검토하십시오. BIOS 설정을 자동 변경하지 않습니다.
조회 방법: GetFirmwareType; HKLM SYSTEM CurrentControlSet Control SecureBoot State.UEFISecureBootEnabled


19. TPM 상태
1. 조치 방법
1) Windows 키+R → tpm.msc 입력 → Enter. 'TPM을 사용할 준비가 되었습니다'와 사양 버전 2.0인지 확인합니다.
2) TPM을 찾지 못하면 담당자가 제조사 안내에 따라 UEFI에서 Intel PTT, AMD fTPM 또는 Security Device Support를 켭니다. 진입 경로는 설정 → 시스템 → 복구 → 고급 시작 옵션 → 문제 해결 → 고급 옵션 → UEFI 펌웨어 설정입니다.
3) 준비되지 않음·오류가 보이면 그 문구를 담당자에게 전달합니다. 'TPM 지우기'나 초기화는 누르지 마세요. 암호화 자료·로그인에 영향을 줄 수 있습니다.
4) 변경·재시작이 끝나면 이 프로그램을 관리자 권한으로 실행해 재점검합니다.

2. 항목의 의미
TPM은 암호화 키 같은 중요한 보안 정보를 보호하는 장치입니다. 장치가 있다는 것과 Windows에서 사용할 준비가 끝났다는 것은 다릅니다.

3. 자세히
기준: TPM 2.0 및 현재 준비 완료는 통과. 미존재·구버전·준비 미완료는 조치 필요.
기존 권고: 상태 코드와 장비 지원 여부를 담당자가 검토하십시오. TPM 초기화·삭제는 자동 실행하지 않습니다.
조회 방법: Win32_Tpm.SpecVersion; IsReadyInformation(IsReady, Information) 상태 조회
